# 小念的自然图鉴

一家人在身边遇见的植物和动物，做成一篇篇图文并茂、可以互动的图鉴，按第一次遇见的日子夹在晾衣绳上。

照片是我们拍的，话是孩子说的，知识有出处。没有后端，发布到 GitHub Pages。和 [小念家的漫画书](https://github.com/handsondad/storyverse) 是同一个系列。

## 本地运行

需要 Node.js 22+。

```bash
npm install
npm run dev
```

推送到 `main` 后会自动部署到 GitHub Pages（仓库 Settings → Pages → Source 选 **GitHub Actions**）。
