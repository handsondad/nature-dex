## 任务类型
🏗️ 基础设施 - CI/CD、部署、监控相关

## 背景与动机
repo 根目录下的 issues 目录用于存放与 规范化/自动化 相关的问题描述文档，需定期检查内容是否齐全、符合最新项目实践。

## 任务范围
**需要做**：
- 审查 issues 目录下所有 issue 文档结构是否规范
- 根据 .github 下 issue 模板对比检查
- 缺失文档按模板补全，冗余内容归档

**不在本任务范围内**：
- 不对 issue 文档中的实际问题内容做决策，只关注格式和项目规范一致性
- 不调整 issue 模板结构

## 完成标准
- [ ] issues 目录下所有文档通过格式检查
- [ ] 缺失 issue 按模板补齐
- [ ] 所有重要内容已对齐最新模板结构

## 技术说明（可选）
可结合 ruff lint、.github/ISSUE_TEMPLATE/task.yml 模板自动化校验格式。
